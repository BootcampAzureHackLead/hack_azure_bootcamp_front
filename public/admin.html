Referencia de Integración Azure

Endpoints Consumidos

  • GET /api/promotion: Devuelve 200 {"message": "..."} al leer mensaje.txt desde Azure Blob Storage con Managed Identity, o 503 {"error": "Promotion unavailable"} si no está configurado o falla.
  • GET /health: Devuelve 200 {"status": "ok"} para validar la disponibilidad del servicio.

Variables de Azure App Service

  • AZURE_STORAGE_ACCOUNT_NAME: Nombre de la cuenta de Storage.
  • AZURE_STORAGE_CONTAINER_NAME: promociones
  • AZURE_STORAGE_BLOB_NAME: mensaje.txt
  • Permiso RBAC requerido: Storage Blob Data Reader asignado a la System-assigned Managed Identity.
